# aarogyam-gym-meal-workout-app
Personalized workout and meal plan generator using Python, Streamlit, and data analytics

## Project Overview
Aarogyam is a data-driven web application that generates personalized 30-day workout and meal plans based on user inputs. The application is designed to support fitness goals by combining structured workout routines with balanced meal recommendations.

The app focuses on providing simple, practical, and user-friendly fitness guidance using data analytics and visualization.

## Tools & Technologies
- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib

## Key Features
- Personalized 30-day workout plan
- Customized meal plans based on fitness goals
- Nutrition tracking (calories and macronutrients)
- Interactive data visualizations
- User-friendly web interface built with Streamlit

## Key Objectives
- Collect user input related to fitness goals and preferences
- Generate structured workout routines
- Suggest balanced meal plans
- Track daily calorie and macronutrient intake
- Visualize fitness and nutrition progress
